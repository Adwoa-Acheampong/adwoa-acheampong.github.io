1. AGL OPS Command Center

LIVE Role: Business Analyst / Digital Integrations Advisor / Systems Lead Link: https://agl.software

Product brief

A live, browser-based ERP and staff operations environment for Automobiles Ghana Ltd. It replaced fragmented paper and spreadsheet workflows with a searchable operating system for workshop activity, vehicle inventory, sales, expenses, staff attendance, HR records and management reporting.

What I designed / delivered

  • Business-process and requirements architecture across workshop, sales, inventory, expense, attendance and staff-record workflows.
  • Kanban-based work-order tracking, QR-code workspace authentication and role-based dashboards for different operational users.
  • Structured data-capture and reporting practices that give management a consistent view of operational and commercial performance.
  • Staff training and adoption workflows, connecting system design to actual day-to-day use rather than treating the platform as a standalone software build.

Technical / systems stack

Application typeWeb-based ERP / staff hub with operational dashboards
Core patternsRole-based access, QR authentication, Kanban workflow management, searchable structured records
Data domainsWorkshop job cards, vehicles, sales, inventory, expenses, attendance, HR and management KPIs
Analytics layerOperational dashboards, performance reporting, data validation and decision-support views
Framework noteThe exact production frontend/backend framework is not documented in the portfolio materials used for this briefing, so it is not overstated here.

Why it matters

AGL OPS is the strongest evidence of systems work moving beyond prototype thinking into a real operational environment. It demonstrates requirements analysis, workflow redesign, data structuring, user adoption, executive reporting and business-impact measurement in one project.

2. Adinkra Intelligence Systems (AIS)

ACTIVE / PROTOTYPE Role: Lead Developer / Engineer / Product Architect Link: https://blkkstarhub.com/adinkra-front

Product brief

The analytics and intelligence frontend for Blkk Star Hub. Adinkra is designed to sit above tenant ERP environments and convert authorised operational data into shared analytics, reporting and artificial-intelligence-assisted decision support. A tenant such as AGL can therefore be viewed from both its ERP operations side and its analytics side.

Implemented technical stack

FrontendReact 19, Vite
UI / stylingTailwind CSS v4, Framer Motion
RoutingReact Router
Data visualisationRecharts
Operational toolingQR workflows; spreadsheet parsing/import/export via SheetJS (XLSX)
ArchitectureMulti-tenant analytics interface connected conceptually to Blkk Star Hub's shared backend and central artificial-intelligence layer

Key engineering highlights

  • Built a data-rich interface for multi-vertical operational metrics and tenant drill-downs.
  • Used Recharts for business visualisation and SheetJS for spreadsheet interoperability, supporting the reality that many SMEs still operate partly through Excel-based workflows.
  • Designed the interface as the decision layer above ERP activity rather than as an isolated dashboard product.
  • Provides the visual foundation for role-specific intelligence for merchants, managers, accountants, financial institutions and investors as the backend matures.

3. BLKK Autos

MVP / VALIDATION Role: Frontend / Mobile Engineer / Product Architect Link: https://blkkstarhub.com/autos-app

Product brief

A universal automotive-commerce application for web, iOS and Android and the first sector-specific validation wedge for Blkk Star Hub. It structures vehicle listings, dealer operations, buyer discovery and transaction workflows while providing a path for verified commercial activity to feed the wider data and analytics architecture.

Implemented technical stack

ApplicationReact Native 0.86
Cross-platform runtimeExpo 57
RoutingExpo Router
StylingTailwind CSS
Motion / interactionReact Native Reanimated and gesture-based interaction
Deployment patternSingle codebase targeting iOS, Android and web; static web bundle / micro-frontend integration within the broader Blkk Star Hub web experience

Key engineering highlights

  • One application architecture serving mobile and web rather than maintaining separate platform codebases.
  • Routing and deep-linking designed for both native navigation and web deployment.
  • Micro-frontend positioning allows the automotive vertical to operate independently while remaining part of the larger Blkk Star Hub ecosystem.
  • Product design is built around the automotive trust problem: structured listings, verification, dealer workflows and transaction history rather than classifieds alone.

4. Blkk Star Hub

PLATFORM BUILD Role: Founder / Strategist / Systems Architect Link: https://blkkstarhub.com

Product brief

A modular, API-first digital trade and business operating system designed to help African MSMEs move from fragmented, locally trusted commerce into structured, verifiable and increasingly financeable operations. The system combines sector-specific commerce frontends with a shared institutional spine for identity, operations, data, analytics, verification, payments, logistics and artificial intelligence.

Current executable components

  • BLKK Autos: cross-platform automotive-commerce MVP.
  • Adinkra Intelligence Systems: shared analytics and intelligence interface.
  • AGL OPS: real-world operational ERP pattern informing the tenant operating-system layer.

Designed / planned platform architecture

Web / mobileReact / Next.js web architecture; React Native / PWA patterns for mobile-first access
Primary dataPostgreSQL with JSONB for flexible cross-vertical catalogue and operating records
SearchTypesense or Elasticsearch for unified cross-vertical search
PerformanceRedis for caching/session management; RabbitMQ for asynchronous events
Identity / APIJWT authentication, API Gateway and modular service boundaries
Distributed workflowsMicroservice-oriented services with Saga-pattern orchestration for cross-service transactions
Payments / commerceDesigned payment orchestration, escrow-state logic, MoMo/card rails and split-payout workflows
IntelligenceAdinkra as the central analytics / artificial-intelligence layer consuming permissioned tenant and transaction data

Sector modules

The broader architecture includes Autos, Merchant, Farmers and Estate verticals. These remain at different maturity levels and should be read as sector-specific expressions of one shared data, trust and operating-system architecture rather than as four unrelated applications.

6. Unified Family Educational ERP

ACTIVE DEVELOPMENT Role: Systems Designer / Builder Link: github.com/Adwoa-Acheampong/Family-Edu-System

Product brief

A multi-tenant, AI-powered family learning ecosystem that gives different family members age-appropriate learning interfaces while using shared infrastructure underneath. The design combines a React/PWA dashboard, Google Workspace services and an AI orchestration layer for content generation, assignments, knowledge retrieval, grading and progress tracking.

Current repository stack

FrontendReact 19, Vite 6, TypeScript
UITailwind CSS 4, Motion, Lucide React
State / dataTanStack React Query, React Router DOM 7
VisualisationRecharts 3
AI SDKGoogle GenAI
Edge / serverCloudflare Workers / Wrangler, itty-router, Express, esbuild
Build / toolingTypeScript, Bun lockfile / npm-compatible scripts, Vite, esbuild

Documented architecture / integrations

  • Google Drive for storage, Google Classroom for LMS/assignment workflows and NotebookLM as a knowledge-retrieval layer.
  • Local AI Engine Room concept with FastAPI, Ollama/local models and OpenRouter model routing.
  • Multi-tenant authentication designed around user isolation and Google OAuth.
  • Offline-ready PWA direction and personalised UI personas for different ages and learning goals.
