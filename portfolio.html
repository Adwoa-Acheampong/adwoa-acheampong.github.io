IN PROGRESS | Independent analytics project

Olist Marketing Funnel & E-Commerce Analysis

Python analysis of lead conversion, commerce-linked sellers and seller-to-customer delivery corridors using public Olist data.

  • Preserves one row per marketing lead by aggregating commerce records before joining seller data.
  • Analysis results: 8,000 leads, 842 closed deals, 10.53% conversion, 380 commerce-linked deals and 45.13% commerce-link rate.
  • Validates 97,811 eligible seller-order records across 412 state corridors; dashboard exports and Looker Studio publication remain pending.

Tools and methods: Python | pandas | Matplotlib | Jupyter | GitHub Codespaces

My independent, self-directed project draws on MIT OpenCourseWare materials.
